# Temperature Converter

A simple web application that converts temperatures between Celsius and Fahrenheit.

## Why I Built This Project

I built this project as a practice project to improve my web development skills.

I wanted to understand how HTML, CSS, and JavaScript work together to create a simple interactive web application.

## Temperature Conversion

### Celsius to Fahrenheit

`°F = (°C × 9/5) + 32`

### Fahrenheit to Celsius

`°C = (°F - 32) × 5/9`
